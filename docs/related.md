# Related projects

CashPilot Android is one part of the CashPilot family. The others:

- [CashPilot](https://github.com/GeiserX/CashPilot): the self-hosted server. It deploys passive income services as Docker containers, collects their balances and shows the fleet, which is where this app's heartbeats land. Its documentation is at [geiserx.github.io/CashPilot](https://geiserx.github.io/CashPilot/).
- [CashPilot-Desktop](https://github.com/GeiserX/CashPilot-Desktop): a desktop app that deploys and monitors the same services on your own computer. Its fleet server accepts this app's heartbeats too.
- [cashpilot-ha](https://github.com/GeiserX/cashpilot-ha): a Home Assistant integration that brings CashPilot's earnings and service states into Home Assistant.
- [cashpilot-mcp](https://github.com/GeiserX/cashpilot-mcp): an MCP server, so an AI assistant can read earnings, manage services and control fleet workers.
