# CLAUDE.md — CashPilot Android

## Overview
Android monitoring agent for CashPilot that tracks passive income apps (Honeygain, EarnApp, Grass, etc.) without root, reporting their status to the CashPilot fleet dashboard via periodic heartbeats.

## Tech Stack
- Kotlin
- Jetpack Compose (UI)
- Gradle (build.gradle.kts)
- Android APIs: NotificationListenerService, NetworkStatsManager, UsageStatsManager
- Fastlane (automated builds/releases)

## Development
```bash
# Build debug APK
./gradlew assembleDebug
# APK at app/build/outputs/apk/debug/app-debug.apk

# Run tests
./gradlew test
```

Requires Android 8.0+ with Notification Access, Usage Access, and Battery Optimization exemption permissions.

## Architecture
- `app/` — main application module
- `app/.../HeartbeatService` — foreground service sending periodic POSTs to CashPilot server
- `app/.../AppNotificationListener` — instant app detection via persistent notifications
- `app/.../AppDetector` — UsageStats + NetworkStats detection
- `fastlane/` — automated build and release configuration
- `docs/` — documentation and images

## Key Rules
- Never hardcode the CashPilot server URL or API key
- Supports 11 passive income apps (EarnApp, IPRoyal Pawns, MystNodes, Traffmonetizer, Bytelixir, ByteBenefit, Grass, Titan Network, Nodle Cash, Uprock, Wipter)
- Uses Bearer auth for server communication
